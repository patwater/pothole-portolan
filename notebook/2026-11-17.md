## Mistakes caught during the run

- **Discover misattributed a source.** The page I archived as the "January 2026 release" is the January 2024 release. I had taken a search snippet's date for the page I was listing. I renamed the source id, corrected its notes, and listed the real 2026 page separately.
- **A wrong value nearly shipped.** The first extraction read "4 blocks resurfaced" because it matched a slide footer page number. I caught it only because the script prints every value. The script now anchors on the full slide sequence. There is no automated test for this trap yet.
- **A stale search snippet became a "discrepancy".** The "good = 64 to 84" band is not on MTC's page, so Discover's second discrepancy was partly an artifact. I have replaced it with the four band schemes that the archives actually contain.
- **The awards table does not add up exactly** ($132.9M of rounded rows against a stated $133.0M). I allowed for rounding and said so in the claim's caveats rather than forcing a match.

## What was learned

- Four incompatible condition band schemes and three different survey-interval statements exist in San Francisco's own documents. A dossier has to quote each source's own bands and never merge them.
- The scorecard pages keep their headline numbers in dashboards, so the archived HTML holds methods but not values. Values need the datasets behind them.
- The schema lacks a kind for program output, so three claims are recorded as `spending` with a caveat. Requested in the proposal.
