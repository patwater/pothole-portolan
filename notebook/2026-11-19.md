## Cloudflare pull request builds failed; fixed

- The build on PR #3 failed. The supervisor pasted the log: pull request branches run `npx wrangler preview`, which needs a `previews` block in the config. I had guessed `versions upload`, which was wrong. Added `"previews": {}` to `wrangler.jsonc`. `wrangler deploy --dry-run` still passes, and `wrangler preview` now gets past that check and stops only at the missing API token, which is expected locally.
- Documented the two commands in `docs/cloudflare.md`.
- Lesson: a failed build's cause is in the dashboard log, and a local dry run of one command does not exercise the other command Cloudflare uses for branches.
